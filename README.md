# TEIN Death Wish

A The End is Nigh mod which adds a new area to the game and a brand new playable character.

This mod is based on [NotWendy's Remake mod](https://steamcommunity.com/sharedfiles/filedetails/?id=2475603754) and uses it as a foundation for the vanilla areas.
